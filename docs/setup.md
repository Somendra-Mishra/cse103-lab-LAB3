# Setup Guide

## Prerequisites

- Python 3.8 or higher
- Git 2.x or higher

## How to Run

```bash
git clone https://github.com/Somendra-Mishra/cse103-lab-LAB3.git
cd cse103-lab-LAB3
python3 src/main.py
```

## Repository Layout

- `src/`   — all source code files
- `tests/` — unit and integration tests
- `docs/`  — additional documentation and guides
